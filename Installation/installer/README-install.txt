# طيف 1.0.9 — التثبيت / Installation

## العربية

1. شغّل الملف `..\dist\Taif_Setup_v1.0.9.exe`.
2. اختر مجلد التثبيت (الافتراضي: `C:\Program Files\Taif`) ثم أكمل الخطوات.
3. ستُنشأ اختصارات على سطح المكتب وفي قائمة ابدأ باسم «طيف».
4. عند أول تشغيل، يحفظ البرنامج إعداداته وسجله في:
   `%APPDATA%\ProMediaDownloader\`

ملاحظات:
- يلزم اتصال بالإنترنت للتنزيل، وبرنامج FFmpeg لدمج الصوت/الفيديو وتضمين الترجمة.
- التثبيت يحتاج صلاحيات المدير (UAC) لأن المجلد الافتراضي داخل Program Files.

## English

1. Run `..\dist\Taif_Setup_v1.0.9.exe`.
2. Choose the destination folder (default: `C:\Program Files\Taif`) and finish the wizard.
3. Desktop and Start-menu shortcuts named “طيف” are created.
4. Settings and history are stored in `%APPDATA%\ProMediaDownloader\`.

Notes:
- An Internet connection is required; FFmpeg is required for merging and subtitle embedding.
- The installer requests administrator rights (UAC) because the default folder is under Program Files.
