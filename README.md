# Pro Media Downloader — برنامج تحميل الوسائط الاحترافي

برنامج مكتبي احترافي لتحميل الفيديو والصوت من يوتيوب وتيك توك وإنستغرام وفيسبوك وأكثر من 1000 موقع، مبني بلغة **Python** وواجهة **CustomTkinter** ومحرّك **yt-dlp**.

الواجهة عربية بالكامل مع RTL وتشكيل الحروف، وتدعم الإنجليزية وتبديل الثيم فوراً. الإصدار الحالي **1.0.9** (طيف / Taif) بثيم افتراضي **forest** فاتح/داكن حسب إعداد النظام.

## التنصيب

### سريع (من المثبت الجاهز)

1. شغّل `Installation\dist\Taif_Setup_v1.0.9.exe`.
2. اختر مجلد التثبيت (الافتراضي `C:\Program Files\Taif`) وأكمل المعالج.
3. تُنشأ اختصارات «طيف» على سطح المكتب وقائمة ابدأ.

### من المصدر

```powershell
# من جذر المشروع
winget install Gyan.FFmpeg
winget install DenoLand.Deno

cd Source
.\setup.bat     # ينشئ ..\.venv ويثبت المكتبات
.\run.bat       # تشغيل
```

أو يدوياً:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r Source\requirements.txt
.\.venv\Scripts\python.exe Source\main.py
```

## الصفحات الثمانية

الشريط الجانبي يحتوي دائماً على **8 عناصر فقط** (مساحة العمل تظهر كطبقة فوقها دون إضافة عنصر):

| # | الصفحة | المحتوى |
|---|---|---|
| 0 | الرئيسية | لوحة إحصائيات + إجراءات سريعة + آخر التحميلات + مساحة التخزين |
| 1 | تنزيل الوسائط | الرابط والمعاينة والجودة والمجلد + حد السرعة والمجموعة |
| 2 | التنزيلات النشطة | المهام الجارية + مركز الفشل + إدارة المجموعات |
| 3 | قائمة الانتظار | الترتيب والأولوية والجدولة |
| 4 | المكتبة | شبكة الملفات المكتملة |
| 5 | سجل التنزيلات | بحث وفرز ومفضلة ووسوم + التحقق من البصمة |
| 6 | أدوات الوسائط | أدوات FFmpeg الثمانية |
| 7 | الإعدادات | اللغة والثيم واللوحات والقواعد والأدوات الاحترافية |

| `F5` | إعادة جلب الرابط الحالي |
| `Ctrl+1` … `Ctrl+3` | التنقل بين الصفحات |

## الميزات المتقدمة

### صندوق الروابط
الصق عدة روابط (سطر لكل رابط أو مفصولة بمسافات) من زر «صندوق الوارد» لإضافتها دفعة واحدة مع إزالة التكرارات.

### مركز الفشل
الأخطاء المؤقتة (شبكة/خادم) تُعاد جدولتها تلقائياً بعد 10 ثم 30 ثم 60 ثانية (3 محاولات). الأخطاء الدائمة تُعرض في مركز الفشل داخل صفحة **التنزيلات النشطة** مع زر إعادة محاولة يدوي. يُحفظ السجل في `failures.json`.

### البصمة والتحقق
بعد كل تحميل يُحسب SHA-256 في خيط منفصل ويُحفظ في السجل. يمكنك إدخال بصمة متوقعة فتظهر شارة «مطابق / غير مطابق». الحجم أو السرعة المجهولة لا تُفعّل أي قاعدة.

### القواعد الذكية
من تبويب «القواعد» في الإعدادات أنشئ قواعد مثل: «الفيديو → مجلد Video»، «الملفات >200MB → Large Files»، «سرعة ≤500KB/s → 720p». أربع قواعد جاهزة معطّلة افتراضياً. القواعد تُطبَّق مرة واحدة لكل طلب (آمنة مع إعادة المحاولة).

### كشف المكررات
من زر «كشف المكررات» في المكتبة: يفحص السجل باستخدام بصمات SHA-256 المحفوظة ثم الاسم+الحجم (بدون قراءة محتوى الملفات). اختر ما تريد حذفه؛ يُنقل إلى **سلة المحذوفات** ويُزال من السجل.

### مجموعات التنزيل
أنشئ مجموعات من صفحة التنزيلات النشطة، ثم عيّن الرابط إلى مجموعة من القائمة المنسدلة في صفحة التحميل. التقدم يُحسب مباشرة، ويمكن بدء/إيقاف كل مهام المجموعة دفعة واحدة. تُحفظ المجموعات في `groups.json` وتبقى بعد إعادة التشغيل.

### النطاق الترددي
اختر حداً لكل تنزيل من القائمة المنسدلة (حسب الإعدادات / بلا حد / قيمة محددة). القيمة `-1` تعني «بلا حد» صراحةً وتتقدم على الحد العام. من قائمة السياق على مهمة جارية يمكنك تغيير حدها **فوراً** أثناء التنزيل.

### مساحة عمل الوسائط
زر «فتح مساحة العمل» في الرئيسية أو الإعدادات يفتح لوحة تجمع الإحصائيات والمهام النشطة وأحدث الملفات والإجراءات السريعة واختصارات الأدوات. الضغط على أي عنصر شريط جانبي يُغلقها تلقائياً.

### التشخيص والإرشاد
زر «فحص النظام» يجري 8 فحوصات بدون اتصال (Python، yt-dlp، FFmpeg، محرك JS، مجلد التنزيل، المساحة، الثيم، السجل، الوكيل). جولة ترحيب من 4 بطاقات تظهر عند أول تشغيل ويمكن إعادتها من الإعدادات.

### إضافات واجهة
إشعارات، وضع مصغّر (Mini Mode)، إيقاف تلقائي بعد اكتمال الطابور، إحصائيات يومية/شهرية، عرض مصغّرات للمهام، ومراقبة الحافظة.

## بناء EXE والمثبت

من **جذر المشروع** شغّل:

```powershell
.\Installation\build_exe.bat
```

أو يدوياً (من مجلد `Installation`):

```powershell
cd Installation
..\ .venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed ^
    --name "ProMediaDownloader" ^
    --icon "..\Source\assets\app.ico" ^
    --add-data "..\Source\assets;assets" ^
    --collect-submodules qrcode ^
    --collect-all tkinterdnd2 ^
    ..\Source\main.py
```

ثم المثبت:

```powershell
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" "Installation\installer\taif_setup.iss"
```

الناتج:
- `Installation\dist\ProMediaDownloader.exe`
- `Installation\dist\Taif_Setup_v1.0.9.exe`

> FFmpeg وDeno برنامجان خارجيان؛ ثبّتهما على جهاز المستخدم أو ضع `ffmpeg.exe` داخل `Source\bin`.

## حل المشاكل

**«ffmpeg غير موجود»**
`winget install Gyan.FFmpeg` ثم أعد التشغيل، أو ضع `ffmpeg.exe` في `Source\bin`.

**يوتيوب يعطي جودات قليلة**
ثبّت Deno: `winget install DenoLand.Deno`، وحدّث `yt-dlp` و`yt-dlp-ejs`.

**البرنامج لا يفتح بعد البناء**
تأكد من أن `--add-data "..\Source\assets;assets"` صحيح وأن الأيقونة موجودة في `Source\assets\app.ico`.

**«python» يفتح Microsoft Store**
استخدم المسار الكامل `.\.venv\Scripts\python.exe`.

**خطأ WinError 32 أثناء كتابة config.tmp**
سببه تشغيل عدة نسخ/اختبارات بالتوازي؛ شغّلها متسلسلة.
